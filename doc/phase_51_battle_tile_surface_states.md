# Phase 51: Battle Tile Surface States

## Status

Planned.

## Goal

Add battle-local tile states so the grid can contain tactical information beyond passable or blocked cells.

Examples:

- burning
- wet
- frozen
- electrified
- smoke
- poison cloud

The first implementation should focus on surface states needed by the minimum elemental slice: burning, wet, frozen, and electrified.

## Why This Comes Before Reactions

Elemental reactions need something stable to react with. Water cannot extinguish fire if the battle state has no durable record of burning tiles. Lightning cannot spread through wet ground if wet ground is only a visual effect.

Phase 51 makes these states part of battle rules.

## State Model

Recommended battle tile state fields:

```text
id: burning, wet, frozen, electrified
cell: Vector2i
layer: surface, air
duration_turns
intensity
source_character_id
source_skill_id
created_round
created_turn
tags
```

Initial layer meanings:

```text
surface: ground state, such as burning, wet, frozen, electrified
air: cloud state, such as smoke or poison, deferred unless needed
```

## Storage

Preferred first pass:

```text
BattleState.tile_states_by_cell
```

Each cell can have one primary surface state and optional secondary metadata. If multiple independent layers become necessary, split storage later:

```text
surface_states_by_cell
air_states_by_cell
```

Do not store tile state only in renderer nodes. The battle rules layer must own the facts.

## Timing Hooks

Phase 51 should define hooks even if some are no-ops until Phase 53:

```text
on_tile_state_created
on_unit_enters_cell
on_unit_starts_turn_on_cell
on_unit_ends_turn_on_cell
on_round_ends
on_tile_state_expires
```

## Visual and Debug Summary

Battle summaries should expose tile state data for overlays:

```text
cell
state_id
duration_turns
intensity
display_color or semantic display id
```

The UI may render highlights from these summaries, but must not mutate tile state.

## Minimum States

`burning`:

- dangerous surface;
- later deals turn-start damage;
- can be extinguished by water.

`wet`:

- non-damaging surface;
- enables ice freezing and lightning spread.

`frozen`:

- movement-affecting surface;
- can later freeze or slow units.

`electrified`:

- short-lived dangerous surface;
- may be generated by lightning reactions.

## Acceptance

Phase 51 is complete when:

- battle state can add, query, refresh, and remove tile states;
- tile states are included in battle summaries;
- tile states expire deterministically;
- existing battles still work when no tile states exist;
- no presentation node owns authoritative tile state.

## Boundary

This phase does not need full elemental reactions. A debug or test skill may apply a state directly, but the reaction table belongs to Phase 52.
