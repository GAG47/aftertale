# v68 区域大地图可视化

v68 做的是区域大地图显示层。它让玩家按 `M` 打开当前生成世界的区域地图，看见区域地貌、世界地点、地点连接，以及自己当前所在地点。

## 已真实接入

- `InputManager` 新增 `M` 键地图开关请求。
- `UIRoot` 新增区域地图面板开关、关闭和刷新流程。
- `WorldTransitionService` 新增区域地图只读数据接口。
- `WorldLocationGraph` 新增读取全部地点、全部边、区域母图的接口。
- `RegionMapView` 使用当前世界数据绘制区域底图、地点节点、地点连接线和地点信息。
- 世界转移完成后，如果区域地图已打开，会刷新当前地点高亮。

## 显示增强

v68 后续整理中，区域地图做了以下显示层改进：

- 生成野外节点的 `display_name` 使用中文展示名；v69 后会优先显示局部角色，例如“森林入口 00”“平原空地 02”。
- `location_id` 仍然保持系统内部 ID，不改成中文展示名。
- 区域地图上的地点圆点旁会显示地点展示名，方便玩家直接看懂节点。
- 正式显示不再绘制整齐调试网格，只保留轻微地貌边界。
- 区域地貌不再只是纯色块：水域有波纹，森林有树冠点，山脚和岩地有山石符号，平原和海岸有轻量纹理。
- 地点连接线改成弯曲点线的旅行路线，用来表达“这些地点相连”。
- 地点节点改成小图标，当前位置改成蓝色定位标记。

这里的道路样式仍然只是区域地图显示，不等于局部场景已经生成连续道路。
地貌纹理也只是 `RegionMap` 的显示方式，不会凭空新增森林、遗迹、河流或地点。

## 数据来源

区域地图显示只读取已有世界事实：

```text
RegionMap：区域地貌母图
WorldLocationGraph.locations：世界地点节点
WorldLocationGraph.exits：世界连接边
WorldTransitionService.current_location_id：玩家当前地点
```

v70 后，地貌底图不再来自单一 `region_map.biome_map`。区域地图从多层区域事实合成显示：

```text
elevation_map：海拔
moisture_map：湿度
water_map：水体强度
forest_map：森林密度
rock_map：岩石强度
slope_map：坡度
water_distance_map：到水体距离
hydro_context_map / landform_class_map / vegetation_class_map / surface_class_map：派生显示语义
```

地点节点使用地点自己的 `region_position`。如果玩家当前在没有区域坐标的子地点，例如室内，地图会显示它的父地点位置；如果找不到带区域坐标的父地点，则不伪造地图位置。

## 只是显示层

区域地图面板不会改变世界数据：

```text
不能点击传送。
不能生成新地点。
不能改变世界边。
不能改变入口规则。
不能绕过 WorldTransitionService。
```

地图面板只调用世界服务的只读接口。它不会写入 `WorldLocationGraph`，也不会调用转场方法。

## 不改变入口规则

v68 保持 v67.1 的规则：

```text
进入地点必须有明确入口。
缺入口直接失败。
入口不存在直接失败。
不使用默认入口。
不使用默认出生点。
不使用第一个候选点兜底。
不使用左上角兜底。
```

区域地图显示当前位置时，只读取已经发生的世界状态，不参与决定玩家从哪里进入地点。

## 未支持

- 不支持在地图上点选地点进行传送。
- 不支持玩家可拖拽或缩放区域地图。
- 不支持正式美术版大地图。
- 不支持跨地点边缘无缝拼接。
- 不支持通过地图发现或生成新地点。
